# November 2026 refresh

Requested scope: all data, copy, and visual design. Keep the existing GitHub
Pages delivery path and the static TypeScript source of truth.

## Approach

Three options considered: a cosmetic reskin (small but leaves the hierarchy),
a new dashboard route (more navigation and duplicate summaries), and an
editorial status brief above the existing race board (recommended). Use the
third: a compact national brief, distinct capacity frames, a readable board,
and consistent dossiers and research ledgers. Keep the industrial navy, blue,
orange, square corners, and system fonts; replace the beige cast with cool
paper surfaces. No decorative photography or invented geographic precision.

## Data specification

When a regulator issues a construction permit without documented physical
nuclear work, move the existing capacity claim into `permitted`. Inputs are
the regulator's decision, the named site, and its electrical design capacity.
The band sits below documented construction and DOE-pathway physical work,
above an application under review. It contributes to executed actions but
never to the being-built total. Preserve the preceding evidence in git and
the refresh record. Operation still requires its own authorization.

Read each new source before using it; cache it and register it. Recheck the
existing citation inventory, distinguishing blocked from dead from changed.
New capture dates describe new reads, not the date an event happened. Keep
historical report estimates labeled by their own publication dates.

## UI specification

Visitors should reach company comparison in the first desktop viewport.
The brief states the tracked sample and its source date, followed by separate
capacity frames. The board retains one fixed gigawatt scale, per-band labels,
and server-rendered rows. Filtering by company/design/lane and sorting by
evidence or announced capacity operate on those same rows. An empty filter
result is explicit. Source details and definitions remain available below.

The header uses a compact brand row and a readable navigation row. It must
not require horizontal page scrolling at tablet or phone widths. The current
route is indicated without color alone. Essential copy stays visible; long
reference ledgers use the existing disclosure pattern. Touch targets are at
least 44px and inputs at least 16px on coarse pointers.
