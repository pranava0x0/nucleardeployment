- 2026-08-05 — DATA-019: Cascade's 320 MWe sat in the contracted band, whose published rule admitted only "an executed offtake, order, or delivery agreement". The evidence is a development-and-funding agreement, which the rule did not cover, so the board counted megawatts as contracted against a rule they did not meet. Root cause: **rule bug**, exposed by the DATA-015 split that put them there. Broadened the published rule to what the band actually accepts, an executed and funded agreement for a named project whether offtake, order, delivery, or development funding, with each claim's label saying which kind it is. The alternative, returning the megawatts to the framework band, would have filed a funded commitment beside unsigned memoranda, which is the conflation this site exists to prevent. The methodology renders the rule from the data, so it updated with it.
